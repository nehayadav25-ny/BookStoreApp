#  BookStoreApp  

A **Full Stack Dynamic & Responsive Web Application** built using the **MERN Stack** (MongoDB, Express.js, React.js, Node.js).  
This project demonstrates the integration of **frontend (React + Tailwind CSS)** with a **backend API (Node.js + Express + MongoDB)** for a complete bookstore management system.  

---

##  Features
- 📖 Browse, Add, and Manage Books  
- 🔐 User Authentication (Signup/Login)  
- 🎨 Responsive UI with Tailwind CSS  
- ⚡ RESTful APIs with Express.js  
- 🗄️ MongoDB Database for storing book and user data  

---

## 🛠️ Tech Stack
**Frontend:**  
- React.js  
- Tailwind CSS  

**Backend:**  
- Node.js  
- Express.js  
- MongoDB (with Mongoose)  

**Version Control:**  
- Git & GitHub
